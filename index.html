01

Market Magic

Course project · COMP 6905 · Node.js and Express

A team web application for daily stock prices. A page takes a ticker and a date range. The server loads open, high, low, and close prices, and can show them as a table, a chart, or a finished page.

I built the server-rendered results page. I also wrote the architecture document and the project README, so the shape of the system is written down where the team can use it.

The course repository is private.

The part I want to get better at is the whole application: deploying a model, designing the system around it, and collaborating on GitHub until the work is something the team can trust.
